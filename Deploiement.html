3. Ce qui a été migré pour Unity 6

ℹ️

Contexte de la migration

Le projet était écrit pour Unity 2018.4.36f1 LTS. Unity 6 (6000.0.47f1) apporte des changements majeurs dans l'API, les packages, le pipeline de rendu et la gestion des composants.

UPDATE
ProjectVersion.txt — Version mise à jour
2018.4.36f1 → 6000.0.47f1
UPDATE
manifest.json — Packages Unity 6 compatibles
  • Supprimé : com.unity.package-manager-ui (supprimé depuis Unity 2019)
  • Supprimé : com.unity.modules.cloth (non nécessaire)
  • Mis à jour : com.unity.cinemachine: 2.7.9 → 3.1.2
  • Mis à jour : com.unity.textmeshpro: 1.4.1 → 3.0.9
  • Ajouté : com.unity.inputsystem: 1.11.2
FIX
TileMapGenerator.cs — Corrections critiques
  • Supprimé : using System.Drawing; — cet espace de noms n'existe pas dans Unity (aucune plateforme). Il causait une erreur de compilation immédiate.
  • Corrigé : Shader.Find("Diffuse") → Shader.Find("Standard") — le shader "Diffuse" a été supprimé depuis Unity 5. En Unity 6, il faut utiliser "Standard" (Built-in) avec un fallback vers "Universal Render Pipeline/Lit".
  • Corrigé : Chemin StreamingAssets — utilisation de Application.streamingAssetsPath au lieu de Application.dataPath + "/StreamingAssets/" pour la portabilité cross-platform.
FIX
AudioManager.cs — Bug critique de composant
  • Corrigé : new AudioSource() → gameObject.AddComponent<AudioSource>() — Il est impossible d'instancier directement un composant Unity. Ce bug existait en 2018 et Unity 6 le vérifie plus strictement.
  • Corrigé : LateUpdate() — suppression d'éléments pendant un foreach levait une InvalidOperationException. Remplacé par RemoveAll().
  • Ajout de Destroy(source) lors de se_stop() pour nettoyer les AudioSource créés dynamiquement.
FIX
MicrophoneRecorder.cs — RequireComponent invalide
  • Corrigé : [RequireComponent(typeof(AudioClip))] — AudioClip n'est pas un Component Unity. C'est un UnityEngine.Object (asset). L'attribut a été remplacé par [RequireComponent(typeof(AudioSource))].
UPDATE
ProjectSettings.asset — Paramètres Unity 6
  • Version sérialisée : 18 → 45
  • Espace colorimétrique : Gamma (0) → Linear (1) (recommandé pour Unity 6)
  • New Input System activé : enableNativePlatformBackendsForNewInputSystem: 1
NEW
Assembly Definition Files (.asmdef) — Système de modules Unity 6
  • Assets/Scripts/LeanTween/LeanTween.asmdef
  • Assets/Scripts/PokemonEssentials/PokemonEssentials.asmdef
  • Bénéfices : compilation incrémentale plus rapide, isolation des dépendances, meilleure organisation.

4. Ouvrir le projet dans Unity Hub

⚠️

Point critique — Quel dossier ouvrir

Vous devez ouvrir le dossier Pokemon Unity/ (avec l'espace), et non la racine du dépôt PokemonUnity/. Le dossier correct contient Assets/, ProjectSettings/ et Packages/.

Cloner le dépôt Git

git clone https://github.com/Lumantis/PokemonUnity.git
cd PokemonUnity
git checkout claude/unity-6.3-migration-XtOmH

Ouvrir Unity Hub et ajouter le projet

  • Ouvrir Unity Hub
  • Aller dans l'onglet Projects
  • Cliquer Add → Add project from disk
  • Naviguer vers PokemonUnity/Pokemon Unity/ et sélectionner ce dossier
  • Unity Hub devrait détecter automatiquement la version 6000.0.47f1

Attendre la compilation initiale

La première ouverture peut prendre 5–15 minutes. Unity va :

  • Importer tous les assets
  • Télécharger les packages (nécessite Internet)
  • Recompiler tous les scripts C#
  • Générer la bibliothèque de données

Vérifier qu'il n'y a pas d'erreurs de compilation

Ouvrez la Console Unity (Window → General → Console). Si des erreurs rouges apparaissent, consultez la section Résolution des problèmes.

5. Configurer la base de données Pokémon

Le projet utilise Veekun's Pokédex — une base SQLite complète contenant toutes les données Pokémon (espèces, attaques, objets, capacités, etc.).

🔴

La base de données n'est pas incluse dans le dépôt Git

Le fichier veekun-pokedex.sqlite est trop volumineux (~374 MB) pour Git. Vous devez le générer ou le télécharger manuellement.

Option A — Générer la base depuis le script SQL

Installer SQLite

# Windows (via Chocolatey)
choco install sqlite

# macOS
brew install sqlite

# Linux (Debian/Ubuntu)
sudo apt install sqlite3

Importer le script SQL

cd PokemonUnity
sqlite3 veekun-pokedex.sqlite < veekun-pokedex.sql

Copier la base dans le projet Unity

# Créer le dossier Data s'il n'existe pas
mkdir -p "Pokemon Unity/Assets/Data"

# Copier la base de données
cp veekun-pokedex.sqlite "Pokemon Unity/Assets/Data/"

Option B — Télécharger la base

Vous pouvez cloner le dépôt Veekun directement :

git clone https://github.com/veekun/pokedex.git
# La base générée se trouve dans pokedex/pokedex/data/

Configuration du chemin dans le code

Dans GameManager.cs (ligne 87–88), la connexion est configurée :

// Chemin relatif par défaut (mode Éditeur) :
Game.DatabasePath = "Data Source=..\\veekun-pokedex.sqlite";

// Pour un build Unity ou chemin absolu, utiliser :
Game.DatabasePath = "Data Source=" + Application.dataPath + "/Data/veekun-pokedex.sqlite";
⚠️

Pour un build standalone

Le fichier veekun-pokedex.sqlite doit être placé dans le dossier Assets/Data/, et la ligne de connexion dans GameManager.cs doit utiliser Application.dataPath. Copier également SQLite.Interop.dll depuis Plugins/ vers le dossier Managed/ du build.

Scène de démo disponible

La scène principale est disponible dans :

Ouvrez-la via File → Open Scene dans Unity, puis appuyez sur Play ▶.

Architecture de chargement des scènes

Le LevelLoader.cs gère les transitions entre scènes avec animation de fondu :

  • LevelLoader est attaché au GameManager (DontDestroyOnLoad)
  • Il écoute l'événement GameManager.current.onLoadLevel
  • Les transitions utilisent LeanTween pour l'animation d'opacité du CanvasGroup
  • La scène est chargée via SceneManager.LoadScene()

9. Builder & exporter le projet

ℹ️

Pipeline de rendu Built-in (BRP)

Le projet utilise le pipeline de rendu intégré (Built-in Render Pipeline), non URP/HDRP. Tous les shaders sont en "Standard". Si vous souhaitez migrer vers URP, il faudra une conversion supplémentaire avec l'outil Unity URP Converter.

Ouvrir Build Settings

File → Build Settings

Ajouter les scènes au build

Cliquez Add Open Scenes pour chaque scène, dans l'ordre de la liste Scenes enum (0=Intro, 1=Load, etc.).

Configurer la plateforme cible

  • Sélectionner Windows, Mac, Linux (Standalone)
  • Architecture : x86_64
  • Scripting Backend : Mono (compatible SQLite natif) ou IL2CPP

Build & Run

Cliquez Build And Run. Après le build, copiez manuellement :

# Copier les DLLs SQLite natives dans le dossier Managed du build
cp "Project DLLs/SQLite/x64/SQLite.Interop.dll" "[Build]/[ProjectName]_Data/Managed/"
# Et la base de données
cp "veekun-pokedex.sqlite" "[Build]/[ProjectName]_Data/"

10. Utilisation des scripts Unity

🎮 GameManager.cs

Singleton principal. Initialise la connexion SQLite, charge les données Pokémon, configure le logger et orchestre toute l'initialisation.

Attacher à : Un GameObject racine DontDestroyOnLoad

Champs Inspector : InputManager, AudioManager, FileTest

🔊 AudioManager.cs

Gestion audio BGM, BGS, ME, SE. Singleton via IAudio AudioHandler. Crée automatiquement les AudioSources via AddComponent.

Attacher à : Le même GameObject que GameManager

Note Unity 6 : Ne jamais utiliser new AudioSource()

⌨️ InputManager.cs + UserInputController.cs

Pont entre Unity Input (legacy) et le système d'input Pokémon. Supporte plusieurs joueurs via des UserInputController indépendants.

Note : Compatible avec le Legacy Input Manager ET le nouveau Input System (activé dans ProjectSettings)

🗺️ TileMapGenerator.cs

Génère la carte du monde 3D depuis les fichiers JSON Tiled (StreamingAssets/MapJson/). Crée mesh, colliders et matériaux à la volée.

Attacher à : Un GameObject avec MeshFilter + MeshRenderer + MeshCollider

Champs : Assigner la Texture dans l'Inspector

📽️ LevelLoader.cs

Charge les scènes Unity avec transitions de fondu. Écoute GameManager.onLoadLevel. Implémente IGameScenesUI.

Champ : canvasGroup — un Canvas plein écran noir pour les fondus

⚔️ BattleScene.cs

Contrôleur principal du système de combat. Implémente IPokeBattle_SceneIE. Gère les animations, les menus, les HP/EXP et les captures.

Nombreux champs : Toutes les références UI doivent être assignées dans l'Inspector

Cycle de vie des MonoBehaviours (Unity 6)

L'ordre d'initialisation dans le projet :

Awake()   → Awake()   → Awake()   (tous les GameObjects)
             ↓
Start()   → Start()   → Start()   (après tous les Awake)
             ↓
Update()  / FixedUpdate() / LateUpdate() (chaque frame)
✅

Bonne pratique Unity 6 — ordre d'initialisation

GameManager.Awake() est le premier à s'exécuter et initialise la connexion à la base. Tous les autres scripts qui dépendent de GameManager.current doivent soit être des singletons initialisés après, soit utiliser Start() plutôt que Awake().

13. Résolution des problèmes courants

❌ Erreur : "Shader 'Standard' not found"

⚠️

Cause : Rendu URP activé sans la pipeline asset correcte

Si vous utilisez URP, le shader "Standard" n'existe pas. Deux solutions :

  • Solution 1 : Utiliser le pipeline Built-in (défaut du projet). Vérifiez dans Project Settings → Graphics que Scriptable Render Pipeline Asset est vide.
  • Solution 2 : Migrer vers URP et changer le shader en "Universal Render Pipeline/Lit". Le code dans TileMapGenerator.cs inclut déjà un fallback automatique.

❌ Erreur : "Can't add component 'AudioSource' because it is not a MonoBehaviour!"

✅

Résolu dans la migration

Ce bug a été corrigé dans AudioManager.cs. Si l'erreur persiste, vérifiez qu'Unity a bien rechargé les scripts (attendre la recompilation ou forcer avec Assets → Refresh).

❌ Erreur : "NullReferenceException in GameManager.Awake()"

⚠️

Cause probable : base de données manquante

Vérifiez que veekun-pokedex.sqlite est présent et que le chemin dans GameManager.cs est correct. En mode éditeur, le chemin relatif ..\veekun-pokedex.sqlite pointe vers le dossier parent du projet Unity.

❌ Erreur : "Assembly 'PokemonEssentials' not found"

💡

Solution : régénérer les fichiers .asmdef

Les fichiers .asmdef ont été créés dans cette migration. Si Unity ne les détecte pas, allez dans Assets → Reimport All. Si les DLLs tierces (PokemonUnity.dll) ne sont pas dans Assets/Plugins/, les référencer manuellement dans l'.asmdef sous precompiledReferences.

❌ Erreur : Package Cinemachine version conflict

💡

Note sur Cinemachine 3.x

Cinemachine 3.x a des API différentes de la 2.x (namespaces, composants renommés). Si vos scènes utilisent des composants Cinemachine de la version 2.x, Unity 6 affichera des avertissements de migration. Utilisez Cinemachine → Upgrade dans le menu Unity pour migrer automatiquement les composants.

❌ Erreur : "Old Input System" warnings

💡

Les deux systèmes d'input sont actifs

Le projet utilise l'ancien système d'input (Input.GetKey()) via UserInputController.cs. Unity 6 supporte les deux systèmes simultanément. Si vous voyez des warnings, allez dans Project Settings → Player → Active Input Handling et choisissez "Both" pour activer les deux systèmes en parallèle.

❌ Erreur : TileMapGenerator ne trouve pas les cartes

⚠️

Vérifier le chemin StreamingAssets

Les fichiers JSON doivent être dans Assets/StreamingAssets/MapJson/. En mode Play, Unity accède à Application.streamingAssetsPath + "/MapJson/map001.json". Vérifiez que map001.json existe bien à cet emplacement.
